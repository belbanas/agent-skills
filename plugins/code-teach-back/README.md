# Code Teach-Back

A 30–60 second comprehension check before you accept, commit, or merge AI-assisted code. Claude does **not** explain the code — it asks you three short questions, one at a time:

1. **Why does it work?**
2. **Why this approach?**
3. **What could break?**

(plus an optional *"what would you inspect first in production?"* for high-risk code), then gives one verdict: **CLEAR**, **GAP**, or **BLIND SPOT**.

## Triggering

Say *"teach-back"*, *"quiz me on this code"*, *"before I merge this"*, *"kérdezz ki a kódról"*, *"mielőtt commitolom"*, or invoke the skill from the `/` menu in Claude Code.
